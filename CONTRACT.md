# Sweep Shift module contract

No runtime dependencies. ESM modules under dist, Node test scripts under scripts. World size 960 x 640. Floor cells are 40px, 24 columns x 16 rows. Floor grid uses 1 walkable, 0 void/wall. Furniture rectangles carve non-walkable cells. Robot radius 17. Art is original Canvas paths; no external fonts/assets needed.

## rooms.js (rooms agent)
Export LOCATIONS array of four objects {name,subtitle,palette:{floor,floor2,wall,accent,dark},trinkets:[six names]}; CAMPAIGN array of 24 metadata objects {id:1..24,name,location:0..3,brief,tip,goldTime,silverTime}; makeRoom(id, seed?) returns fresh deterministic room {id,name,location,seed,width:960,height:640,grid:2D array,obstacles:[{x,y,w,h,kind}],stations:[{x,y}],spawn:{x,y},fans:[{x,y,w,h,dx,dy,strength}],debris:[{id,x,y,type:'crumb'|'confetti'|'dust'|'stuck',value:integer}],trinket:{x,y,name},goldTime,silverTime,tip}. makeEndless(seed) same shape id:0 and name Endless Shift. Export isWalkable(room,x,y,radius=17). Ensure floor connected, robot clearance, stations reachable and all debris collectible; floor sample positions must be valid for radius 18. First room ~230 debris, later 270-420, hard upper bound 440. Use different authored obstacle/floor layouts and distribution clusters, not only different random seeds. Station auto-unload range 48 from center; station is not a collision obstacle. Avoid narrow or point-connected passageways. Return grid WITH obstacle cells already zeroed. Layout reachable checker tests across 24 plus 100 seeds.

## progression.js (progression agent)
Export SAVE_KEY='sweep-shift-career-v1', defaultCareer(), validateCareer(raw), loadCareer(storage), saveCareer(storage,career), statsFor(upgrades), UPGRADES, SHELLS, upgradePrice(key,rank), buyUpgrade(career,key), settleRun(career,result), selectShell(career,id), isRoomUnlocked(career,id).
Career shape {version:1,coins:0,unlocked:1,completed:[],medals:{},bestTimes:{},trinkets:[],upgrades:{width:0,bag:0,speed:0,pull:0},shell:'mint',settings:{muted:false,effects:0.65,reducedMotion:false},lastRoom:1,endingSeen:false}. completed/trinkets arrays of IDs. Medals numeric 1 bronze 2 silver 3 gold keyed room id. buyUpgrade/selectShell mutate career and return {ok,message}; settleRun mutates career returning {coins,bonus,newMedal,newTrinket,newShell,endlessUnlocked}; result {runId:string,roomId:1..24 or 0,coins:integer,time:seconds,medal:1..3,trinket:boolean}. Must reject duplicate run IDs using bounded career history; completion/medal/trinket bonuses only first/improvement. Return coins total awarded including base. loadCareer returns {career,status:'ok'|'new'|'blocked'|'recovered'}; saveCareer returns bool. statsFor returns {radius:54..94,capacity:90..240,speed:150..225,pull:1..2.25}. UPGRADES array {key,name,description}, five ranks each; SHELLS [{id,name,color,unlockAfter:0/6/12/18/24}]. Original-code-drawn cosmetics. No bonus for endless uniquecompletion. Upgrade costs are 180, 320, 550, 900, and 1,350 coins per category. A first campaign clear funds all 20 ranks without replay grinding.

## simulation.js (root)
Export createRun(room,stats,runId), step(run,dt,input), runResult(run), moveTo helper optional. Input {x,y} directional normalized vector. run {room,stats,runId,phase:'playing'|'finishing'|'complete',robot:{x,y,angle,move,bag,bagValue,squash},debris:[...room.debris,{vx,vy,angle,amount:1,collected:false}],trinket:{...room.trinket,collected:false},cleaned:0,total:number,percent:0,coins:0,time:0,unloading:0,nearestStation:0,full:false,finishProgress:0,particles:[],events:[],collectedCount:0}. Time active only; input is collision constrained. Cleaned can be fractional dust; percent cleaned/total. events drained by app [{type:'pickup'|'unload'|'full'|'trinket'|'finish',material?,value?}]. particles [{x,y,vx,vy,life,maxLife,color,size}]. Simulation owns particles updating. Auto suction line-of-sight must not collect through walls. 95% finish cleans remaining, pays bag/remaining, retains actual trinket optional. runResult returns progression result. No negative currencies, no repeated payout after complete.

## render.js (visual agent)
Export render(ctx,run,options={time:0,reducedMotion:false,shellColor:'#84d9b3',pointer:null}), drawTitle(ctx,time,reducedMotion=false). Caller transforms canvas to world 960x640; render draws entire room at those coordinates. Do not resize canvas or mutate run. Renderer must draw void/background, clean floor pattern, furniture appropriate to location, debris incl dust amount fade, fans, stations with label/nearest hint when bag >=80%, optional visible trinket, robot with eyes/antenna/brushes/bag window, pull trails/particles, unloading stream and final sweep pulse. Robot suction field should be a soft subtle highlight, not big opaque circle. Help make movement and suction toy-like and readable. Room drawing may use internal caching keyed room seed/id. Fonts system sans-serif only. Keep render performant on midrange devices. drawTitle draws an attractive original code illustration (robot+debris+floor) in 960x640 space for title card and marketing cover export.

## app.js/style.css/index.html (root)
Root owns interface, input, screens, audio, UI accessibility, responsive, testing integration, release, and browser playtest. Other agents must not edit these. Root may adjust modules after agent handoff.
